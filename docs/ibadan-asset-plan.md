# Ibadan visual reference and asset plan

All geometry currently shipped is original procedural artwork. It is a schematic interpretation of the supplied scene proposals, not a dated survey or authentication of a building, costume or personal likeness. The visible stage label says “Interpretive space · composite figures”; the evidence panel explains the particular limits.
