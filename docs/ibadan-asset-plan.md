[The research record](research/ibadan-3d-direction.md) lists the technical references actually inspected and online sources the network prevented accessing. MakeHuman graphical assets are CC0; its AGPL application code was not imported.

The supplied historical register's remaining access limits continue to apply. Authentication of personal likenesses, specific costume, building plans, equipment and oral histories needs appropriate archive/community visual evidence. The current gallery does not substitute another identifiable person's scan for a historical subject.
