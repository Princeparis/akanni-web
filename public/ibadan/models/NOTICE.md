# Ibadan portrait studies

The two GLB heads are derived from MakeHuman's hm08 base mesh and bundled African female/male young/old graphical targets. Those graphical inputs explicitly carry CC0-1.0. See MAKEHUMAN-CC0.txt for the full licence. No MakeHuman application source code is included.

Upstream graphical data: https://github.com/makehumancommunity/makehuman
Copyright holders named in the input headers: Data Collection AB; Joel Palmius; Jonas Hauquier (2020).

Original adaptation: target blending, head/neck crop, one Catmull–Clark subdivision, normal generation and GLB packaging. Exact input URLs and SHA256 digests are recorded in docs/research/ibadan-model-sources.json; the builder is scripts/build-ibadan-models.py.

These are artist's interpretations, not authenticated historical likenesses, individual scans or verified costume evidence. The composite artist is not a portrait of a named Mbari member. Clothing, accessories and the gallery's other object/architectural models are original artwork in the source code.
